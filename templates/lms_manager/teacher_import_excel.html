Hướng dẫn chuẩn bị File Excel/CSV
  1. Hệ thống chấp nhận tệp định dạng **CSV** (phân tách bằng dấu phẩy `,`). Bạn có thể thiết lập file trong Microsoft Excel hoặc Google Sheets rồi chọn **Save As -> CSV UTF-8 (Comma delimited) (*.csv)**.
  2. File tải lên cần tuân thủ cấu trúc chính xác gồm **2 cột** theo thứ tự:
    • Cột 1: **Tên Lớp học** (ví dụ: `10A1`, `11B2`, `Lớp Toán nâng cao`)
    • Cột 2: **Môn giảng dạy** (ví dụ: `Toán học`, `Vật lí`, `Tiếng Anh`)
  3. Hệ thống sẽ **tự động viết hoa/chuẩn hóa** tên lớp và tên môn học, đồng thời tự động tạo mới lớp học/môn học nếu chúng chưa có trong cơ sở dữ liệu.
